# Accounta — サービス構想

## Accountaとは

Accountaは、個人事業主、マイクロ法人、小規模組織、会計学習者を主な対象とした、**会計・予実管理と業務分析のためのアプリケーション**である。

予算、実績、固定資産、仕訳、帳簿、財務諸表、証憑などを関連付け、日々の管理業務を分かりやすく、扱いやすくすることを目指す。

当初は個人開発・技術検証として進める。将来的には経理・管理部門の業務効率化や、会計・原価・経営管理の分析支援に活用することを想定する。

## 目指す価値

- **情報をつなぐ**：予実管理、会計、固定資産、証憑などを同じ文脈で参照できるようにする。
- **管理・分析を容易にする**：Excel出力や標準ダッシュボードを通じて、数値の確認、差異把握、報告を支援する。
- **定型業務を減らす**：OCR、仕訳候補、AI、MCP等を段階的に活用し、入力・確認・分析の負担を減らす。
- **学習と業務知識を支える**：会計基準、会計処理の考え方、財務諸表論等の学習・知識整理にも利用する。
- **将来のERP活用につなげる**：必要性と接続条件が整えば、SAP S/4HANA等の業務データを活用した分析・意思決定支援へ発展させる。

## サービスの位置付け

Accountaは、SAP S/4HANA等のERPそのものを置き換えることを目的としない。自前の管理データ、外部システムの正式な業務データ、分析ノウハウを結び付ける、**管理業務・分析・AI活用の補完レイヤー**を目指す。

利用者の所属会社・組織と権限に応じて、参照・操作できる情報を適切に制限する。会計データについては、正確性、貸借一致、金額精度、追跡可能性を重視する。

## 実現の考え方

1. **基本機能を小さく作る**：会計・予実管理の実用的な機能を段階的に整える。
2. **使いやすくつなぐ**：帳簿、固定資産、予実、Excel、Chart.jsによる標準ダッシュボードの連携を改善する。
3. **必要に応じて高度化する**：OCR、自動仕訳、学習・ナレッジ、外部ERP連携、AI分析などを優先度に応じて追加する。

これは方向性であり、固定的なリリース順序・実装時期を示すものではない。
