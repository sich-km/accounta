# DatabaseSeeder 仮定法人

## 目的

`DatabaseSeeder` が登録する初期サンプルデータは、画面表示、仕訳入力、予実比較および固定資産管理を一貫した事業前提で確認するためのものです。

金額と取引内容は動作確認用の仮定であり、実在する法人の業績や会計処理を表すものではありません。

## 法人の概要

| 項目 | 前提 |
| --- | --- |
| 会社コード・会社名 | `KM` |
| 組織名 | `KM` |
| 会社規模 | 創業者1名と社員1名の小規模法人 |
| 創業者 | 経営と自社SaaS・受託システムの開発を担当 |
| 社員 | 顧客対応、保守、販売業務を担当 |
| 社員給与 | 月額200,000円 |
| 創業者役員報酬 | 月額250,000円 |
| 法定福利費 | 月額70,000円 |
| 目標利益 | 月額おおむね300,000円 |

## 事業内容

### 自社SaaS事業

- 自社開発したSaaSをサブスクリプション形式で提供する。
- SaaS内の広告掲載からも収益を得る。
- 主な担当部門は `D310 ソフトウェア開発部` とする。

### IT支援事業

- 顧客の要望に応じたシステムを受託開発する。
- 納品後のシステム保守サービスを提供する。
- 開発は `D310 ソフトウェア開発部`、保守は `D210 CS統括部` を主担当とする。

### 小売事業

- 商品Aを仕入れ、顧客へ販売する。
- 仕入額は販売額のおおむね60%を想定する。
- 主な担当部門は `D410 国内営業部` とする。

## 部門の使い分け

| 部門 | サンプルデータ上の役割 |
| --- | --- |
| `D100 経営企画部` | 創業者役員報酬、事務所賃借料、消耗品費、共通資産 |
| `D110 経理部` | 決済・振込手数料、入出金管理 |
| `D120 人事部` | 社員給与、法定福利費 |
| `D130 情報システム部` | NAS・ネットワーク機器 |
| `D210 CS統括部` | 顧客システムの保守サービス |
| `D310 ソフトウェア開発部` | SaaS、広告、受託開発、クラウド、開発外注 |
| `D410 国内営業部` | 商品Aの仕入・販売、広告宣伝 |

`DepartmentSeeder` には画面と組織管理の確認用として、上表以外の部門も登録します。

## 仕訳データ

`JournalEntrySeeder` は2025年1月から12月までと、2026年1月から9月までの取引を登録します。

毎月、次の取引を想定しています。

- SaaSサブスクリプション売上と広告収入
- 商品Aの仕入、販売および買掛金の支払
- 受託システム開発・保守売上と売掛金の回収
- 社員給与、創業者役員報酬および法定福利費
- クラウド利用料、事務所家賃、広告宣伝費、手数料、消耗品費および開発外注費

また、6月には決算・財務会計機能の確認用として、次の臨時取引を登録します。

- 旧ネットワーク機器の売却日までの減価償却費20,000円
- 旧ネットワーク機器の売却による固定資産売却益20,000円
- 投資有価証券の実質価額下落に伴う減損処理（投資有価証券評価損30,000円）

さらに、2025年5月に取得した業務用iPadが2026年9月5日に故障した想定で、前期減価償却費20,000円、当期減価償却費22,500円および固定資産除却損77,500円を計上します。2026年9月10日には買替用iPadを取得します。

## 固定資産データ

`FixedAssetSeeder` は、この法人が事業に利用する次の資産を登録します。

- 創業者開発用ワークステーション
- 社員業務用ノートパソコン
- バックアップ用NAS・ネットワーク機器
- 自社SaaSプラットフォーム
- 商品A保管・梱包設備
- 事務机・チェア一式
- 2026年6月に売却した旧ネットワーク機器
- 2026年9月に故障除却した業務用iPad
- 故障除却後に取得した買替用iPad

保有中の資産は当期の減価償却仕訳をまだ計上していない前提で、当期減価償却費を0円とします。売却済みの旧ネットワーク機器と除却済みのiPadだけ、売却日・除却日までの当期減価償却費を保持し、取得価額、減価償却累計額および帳簿価額を仕訳と一致させています。
